# Blueprint projects

Validates compact Sponge-converted JSON, transforms coordinates/states, counts
materials, plans dependencies and schedules bounded project regions. Project
verification includes air cells; optional site clearing is explicitly gated.

See [blueprint conversion](../../docs/blueprints.md),
[production planning](../../docs/production.md), and
[project commands](../../README.md#request-materials-and-build-a-project).
